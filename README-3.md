# TanishuvBot — GitHub/Render fayllari

- `app.py` — Telegram bot kodi
- `requirements.txt` — kerakli Python kutubxonasi
- `render.yaml` — Render background worker sozlamasi

## Render'da sozlash
Render'da servis yaratilgach, Environment bo'limiga:
- `BOT_TOKEN` — BotFather'dan olingan yangi token
- `ADMIN_ID` — admin Telegram raqamingiz (raqam ko'rinishida)

Bot tokenini GitHub kodiga yozmang. Agar eski token oshkor bo'lgan bo'lsa, BotFather orqali uni bekor qilib, yangisini oling.

Eslatma: botning boshqa sozlamalari, jumladan karta ma'lumotlari va admin username'i `app.py` ichida namunaviy qiymatlarda qolgan. Ishlatishdan oldin ularni o'zingizga moslang. Kod Telegram'da jonli sinovdan o'tkazilmagan.
